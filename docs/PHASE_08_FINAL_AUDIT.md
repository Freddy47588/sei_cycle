## Reading the matrix

Paths below are relative to the repository. Within `lib/features/`, a feature's named screen and service are its actual source implementation; `screen/` and `services/` are used unless explicitly shown otherwise. Test paths are under `test/` unless prefixed otherwise. Tests listed are inspected coverage, not a claim that every scenario or every role has run on Android.

- **S**: source and existing automated test contracts inspected; Phase 08 execution results are in the test report.
- **D**: physical Android/manual acceptance is **PENDING**, using the [UAT checklist](PHASE_08_UAT_CHECKLIST.md).
- **P**: privileged end-to-end production availability is **BLOCKED/UNVERIFIED** pending trusted worker hosting and approved staging/production acceptance. Phase 08 read-only checks verified deployed Rules/indexes as recorded below; that does not verify a running worker.
- **A**: authenticated active supported roles. **O**: active Admin or field operator, including legacy `operator`. **F**: active Admin or finance operator. **Admin**: active Admin only. Mitra and education participant legacy roles have read access to allowed operational data, not management or Finance. Unknown roles fall back to restricted UI capabilities; Rules remain authoritative. Inactive and unauthenticated access must fail closed.

Unless a row says otherwise: no additional feature defect was confirmed in this source review, no row-specific fix was applied, and the remaining limitation is D. The findings table records changes and unresolved defects explicitly. An S/D result is **not** a full release PASS.
